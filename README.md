# fwdio

> Fine. We'll do it ourselves.

Self-contained, agent-runnable **kits**: plain markdown files that hand an
ordinary person real leverage. Drop a kit into your AI agent (built for Claude
Code, works anywhere) and say **"read this and run it."** The work happens on
your machine — fwdio hosts the intent; your AI supplies the labor.

Live at [fwdio.org](https://fwdio.org).

## Kits

- [`the-seed.md`](the-seed.md) — a kit that makes kits. Interviews you about
  what you're up against, tells you honestly when a markdown file isn't the
  answer, and co-builds a new kit for your situation.
- [`policy-eval-kit.md`](policy-eval-kit.md) — turns a written policy into a
  running evaluation: rubric with anchors, boundary-heavy test set, blind
  grading with a calibration number, and a report someone can act on.
- [`the-council.md`](the-council.md) — convenes five minds around your hardest
  decision: blind pitches, forced dissent, a forged top three, one honest
  quarrel, and a verdict with kill criteria and a minority report.

## Norms

- **Curation over volume.** Five great kits beat fifty.
- **Honesty over hype.** Every kit must be able to say "a markdown file isn't
  the answer here." Crime, HR matters, and mental-health crises route to real
  human resources, always.
- **Dumb-simple hosting.** Static page, raw `.md` downloads. No backend.
