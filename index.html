Fine. We’ll do it ourselves.

Self-contained kits — plain markdown files — that hand an ordinary person real leverage. Drop one into your AI agent and the work happens on your machine. No accounts, no backend, nothing running on ours. The file is the product.

```how to run a kit
  1. download a kit — it’s just a .md file
  2. drop it in a fresh folder and open your AI agent (built for Claude Code, works anywhere)
  3. say: “read this and run it”
```
## kits — two so far, on purpose

the-seed.md

A kit that makes kits. It interviews you about what you’re up against, tells you honestly if a markdown file isn’t the answer, and co-builds a new kit for your situation — one you can keep, rerun, and hand to the next person.

raw .md

policy-eval-kit.md

Turns a written policy into a running evaluation. For the trust-and-safety analyst who knows exactly what “violating” looks like and was told the checking is an engineering problem. Rubric with anchors, boundary-heavy test set, blind grading, a calibration number, and a report someone can act on.

raw .md

Curation over volume: five great kits beat fifty. Every kit is required to say “a markdown file isn’t the answer here” when it isn’t — crime, HR matters, and mental-health crises route to real humans, always.
